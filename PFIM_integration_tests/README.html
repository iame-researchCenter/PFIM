PFIM 8.0.1 — Integration tests

Folder PFIM_integration_tests/ · repository iame-researchCenter/PFIM

End-to-end validation for beta testers: FIM evaluation, design optimization, and covariates / IOV.

Workflow

Install PFIM → setwd to PFIM_integration_tests/ → source("run_tests.R") or Rscript run_tests.R. Outputs are written under each script’s results/ folder.

Requirements

ComponentPurpose
R ≥ 4.5, PFIM 8.0.1FIM and optimization
Pandoc (recommended)HTML reports via Report()

Running the test suite

Terminal

cd PFIM_integration_tests
Rscript run_tests.R
Rscript run_tests.R --sections=cov,evaluation,optimisation

R / RStudio

setwd("path/to/PFIM/PFIM_integration_tests")
source("run_tests.R")

Sys.setenv(PFIM_TEST_SECTIONS = "cov")
source("run_tests.R")

Sys.unsetenv("PFIM_TEST_SECTIONS")
source("run_tests.R")
